# Installing Quick Chat

Quick Chat is a web app you can install from your browser. It then opens in its own window, with its own icon, like a native app. There is no app-store download: no Android APK or iOS IPA exists, and none is needed.

Address: **https://quickchat.akarikatechnologies.me**

## Android (Chrome, Edge, Brave, Samsung Internet)

1. Open the address above in your browser.
2. Tap **Install app** on the home page, the sign-in page, or in **Settings**.
3. Confirm **Install**.

If the button doesn't appear, open the browser menu (⋮) and choose **Install app** or **Add to Home screen**. Brave sometimes offers only the menu option.

## iPhone and iPad (Safari)

Apple doesn't let websites show an install prompt, so Quick Chat shows these steps when you tap **Install app**:

1. Open the address in **Safari**. Other iOS browsers can also add to the Home Screen on iOS 16.4 and later.
2. Tap **Share** (the square with an up arrow).
3. Choose **Add to Home Screen**.
4. Tap **Add**.

## Windows, macOS, Linux (Chrome, Edge, Brave)

Click **Install app** on the home page, the sign-in page or in Settings. You can also click the install icon at the right end of the address bar.

## Mac (Safari 17 or later)

Click **Install app** for the steps, or choose **File → Add to Dock…** in Safari.

## Firefox

Firefox on desktop can't install web apps, so the button is hidden there. Use Quick Chat in a tab, or install it from Chrome, Edge or Brave.

## After installing

- Sign in once inside the installed app. On iPhone, the Home Screen app keeps its own sign-in, separate from Safari.
- Google sign-in works inside the installed app.
- Updates install themselves. A new version loads the next time you open the app.
- Offline, the app shows an offline page. Chats need a connection, and private messages and media are never stored for offline use.

## Uninstalling

- **Android:** long-press the icon → Uninstall.
- **iPhone:** long-press → Remove App.
- **Desktop:** open the app → ⋮ → Uninstall Quick Chat.
